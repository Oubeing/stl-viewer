# STL Viewer —— Python 实现

一个用**纯 Python** 实现的 STL / PLY 三维模型查看器。本项目重建了常见三维
查看器的核心能力：模型读写、轨道相机、**双渲染后端**（OpenGL 硬件视口 +
numpy 软件光栅化）、线框 / 实体 / 彩色 / 透明显示、光照设置、坐标轴与十字线、
2D/3D 测量、多对象场景、单位换算、多语言、旋转动画、宏录制与截图导出。

> 图形界面优先使用 PyQt5 自带的 `QOpenGLWidget`（VBO + GLSL，硬件深度缓冲），
> 几十万至上百万三角面也能实时旋转；没有 GL 上下文时自动回退到自研软件
> 光栅化（Z-buffer + 画家算法 + 线性增量边函数），该后端仅依赖 numpy。
> 自带 PNG 编解码器与 5×7 位图字体，**不依赖 Pillow / PyOpenGL 等额外包**；
> 命令行模式不需要 PyQt5。

---

## 1. 功能特性

- **模型读写**：STL（二进制 / ASCII）、PLY（含顶点色）、以及打包 / 自包含导出件中内嵌的模型。
- **双渲染后端**：OpenGL 硬件视口（`QOpenGLWidget`，VBO + GLSL，4× MSAA）为主；
  无 GL 时自动回退到 numpy 软件光栅化（Z-buffer + 画家算法）。
- **显示模式**：线框 / 实体 / 彩色（整件同色、按分量、按曲率、按法向）/ 透明。
- **光照**：预设（默认、工作室、金属、平坦…）+ 环境光 / 漫反射 / 高光调节。
- **轨道相机**：透视 / 正交、标准视图、围绕画面中心的旋转 / 平移 / 缩放。
- **测量工具**：点、直线（3D / 2D）、两点圆、三点圆、角度、RZ 点；标注叠加在画布上。
- **坐标轴 / 网格 / 十字线**：辅助定位与比例判断。
- **多对象场景**：同时载入多个模型、分别着色与统计。
- **单位换算**：mm / inch 切换。
- **多语言**：内置 15 种界面语言。
- **旋转动画 / 宏录制**：多种轴向与速度，可录制与回放。
- **截图与导出**：PNG（含透明背景）、剪贴板，命令行批量渲染 / 转换 / 拆分。

## 3. 安装与运行

```bash
# 1) 安装依赖
pip install -r requirements.txt        # numpy>=1.22（必需），PyQt5>=5.15（可选）

# 2) 启动图形界面
python run_viewer.py                   # 最大化窗口启动，空场景（0 objects）
python run_viewer.py model.stl         # 启动并打开单个模型
python run_viewer.py a.stl b.stl       # 启动并同时打开多个模型

# 等价的模块方式
python -m stl_viewer model.stl

# 3) 无图形环境 / 批处理 → 命令行模式
python -m stl_viewer --cli --help
```

> 无 PyQt5 时，直接运行会给出安装提示，命令行模式不受影响。

> **启动状态**：窗口默认最大化，场景里没有任何 objects（不再自动生成示例
> 毛坯），Objects 面板为空；画布中央显示视图原点标记与载入提示。模型仅通过
> `File > Open`、拖放或命令行参数进入场景，载入后自动居中到画布中心。

## 4. 命令行接口（CLI）

```bash
python -m stl_viewer --cli <子命令> [参数]
```

### 4.1 `info` —— 统计模型与文件信息

```bash
python -m stl_viewer --cli info samples/drill_blank.stl
python -m stl_viewer --cli info model.stl --json   # JSON 输出
```

输出：三角形/顶点数、包围盒、表面积、体积、连通分量数、退化面数、
边界边数、非流形边数、水密性判断等。

### 4.2 `render` —— 渲染图片

```bash
# 实体 + 抗锯齿，双倍分辨率
python -m stl_viewer --cli render model.stl -o out.png --double --antialias

# 线框 + 网格 + 坐标轴，指定视角与尺寸
python -m stl_viewer --cli render model.stl -o wire.png --wire --grid --view iso

# 按连通分量着色
python -m stl_viewer --cli render model.stl -o parts.png --component-colors

# 法向彩虹图 / 平滑着色
python -m stl_viewer --cli render model.stl -o n.png --orientation
python -m stl_viewer --cli render model.stl -o s.png --smooth

# 透明背景导出
python -m stl_viewer --cli render model.stl -o out.png --transparent

# 任意朝向
python -m stl_viewer --cli render model.stl -o v.png --yaw 35 --pitch 20
```

常用参数：`-o/--output`、`--size WxH`、`--view {iso,iso_back,front,back,left,right,top,bottom}`、
`--yaw`、`--pitch`、`--ortho`、`--wire`、`--colored`（整件同色，默认）、
`--uniform`、`--component-colors`、`--curvature-colors`、`--orientation`、
`--smooth`、`--edges`、`--grid`、`--crosshair`、`--no-axis`、
`--transparent`、`--transparent-object`、`--alpha`、`--background`、`--gradient`、
`--supersample N`、`--antialias`、`--double`、`--no-weld`、`--json`。
载入时默认自动焊接重合顶点（STL 多为未焊接的三角汤），`--no-weld` 可关闭。

### 4.3 `convert` —— 转换 / 修复 STL

```bash
python -m stl_viewer --cli convert in.stl -o out.stl --ascii    # 转 ASCII
python -m stl_viewer --cli convert in.stl -o out.stl            # 转二进制（默认）
python -m stl_viewer --cli convert in.stl -o out.stl --weld --repair
python -m stl_viewer --cli convert a.stl b.stl --repair         # 批量，自动命名 *_out.stl
```

参数：`files...`（一个或多个输入）、`-o/--output`（单文件时指定输出）、
`--ascii`、`--weld`、`--repair`、`--tolerance`。输出目录不存在时会自动创建。

### 4.4 `components` —— 拆分为连通分量

```bash
python -m stl_viewer --cli components model.stl --weld \
    --out-prefix parts/part --min-triangles 1
```

参数：`file`（输入）、`--out-prefix`（输出前缀，目录自动创建）、
`--min-triangles`（小于该面数的分量跳过）、`--weld`、`--repair`。
输出命名为 `<prefix>_part01.stl`、`<prefix>_part02.stl`……

### 4.5 `measure` —— 测量计算

所有测量都以**文件为第一个参数**，用选项指定几何，点之间用 `;` 分隔：

```bash
# 两点距离
python -m stl_viewer --cli measure model.stl --line "0,0,-20;0,0,20"

# 三点定圆（圆心 / 半径 / 直径）
python -m stl_viewer --cli measure model.stl --circle "0,0,0;10,0,0;5,8,0"

# 两点定圆
python -m stl_viewer --cli measure model.stl --circle "0,0,0;10,0,0"

# 三点夹角（第一点为顶点）
python -m stl_viewer --cli measure model.stl --angle "0,0,0;1,0,0;0,1,0"

# 单点 / RZ 点（柱坐标）
python -m stl_viewer --cli measure model.stl --point "1,2,3"
python -m stl_viewer --cli measure model.stl --rz "10,0,5"

# 指定 Z 高度处的最大回转半径
python -m stl_viewer --cli measure model.stl --radius-at 5

# 英寸单位 + JSON 输出
python -m stl_viewer --cli measure model.stl --rz "10,0,5" --units inch --json
```

## 5. 图形界面

界面按常规三维查看器组织。窗口**启动即最大化且没有任何 objects**；
画布中心是视图原点（旋转 / 缩放支点），并有一个低调的中心标记：

- **文件 File**：打开 / 追加 / 关闭 / 导出 STL（ASCII、二进制）/ 保存图片
  （PNG、剪贴板、透明背景版）/ 最近文件 / 退出。
- **视图 View**：标准视图（等轴、前后左右、上下）/ 透视与正交切换 /
  重置 / 适配窗口 / 视图选项（显示坐标轴、网格、十字线、边线、背景渐变，
  以及**鼠标灵敏度**与**拖拽画质 / 抗锯齿 / 载入时焊接顶点**等选项）。
  > **默认正交投影**：为让检测/测量严格等比例（正视圆为正圆、测量即真实尺寸），
  > 启动时即为正交；需要近大远小的立体感时用 `View > Orthogonal` 切回透视。
- **网格 Mesh**：焊接顶点 / 移除退化面 / 修复法线 / 翻转法线 /
  双面显示（Back and Front，默认关闭即剔除背面）/
  着色模式（整件同色、按分量、按曲率、按法向）/ 统计信息 / 分割连通分量 / 删除选中。
- **光照 Light**：预设（默认、工作室、金属、平坦…）、环境光/漫反射/高光调节。
- **测量 Measurement**：点、直线(3D)、直线(2D)、两点圆、三点圆、角度、RZ 点；
  标注显示在画布上；可清除。
- **附加 Extras**：旋转动画（多种轴向与速度）、宏录制/播放/存取、
  语言切换（15 种）、单位切换（mm / inch）。
- **帮助 Help**：关于对话框。

**两行工具条**（常用项不再藏在多级菜单里）：

| 行 | 内容 |
|----|------|
| 第一行「视图」 | 放大 / 缩小 / 适应窗口 / 复位中心 / 旋转角度 · **8 个标准视图按钮**（等轴测、前后左右、俯仰、后等轴测，对应快捷键 `1`~`8`）· 切换视角自动适配开关 · 绕 Z 旋转 / 正交投影 / 全屏 / 视图选项 |
| 第二行「主」 | 打开 / 保存图片 / 线框 / 实体 / 彩色 / 透明 / 棱边 / 十字线 · **着色模式下拉**、**光源预设下拉** · 5 种测量 · 旋转动画 / 统计 |

切换标准视角默认会**同时重新 Zoom Fit**，模型按新朝向铺满画布；不想自动
缩放时，取消第一行「切换视角自动适配」勾选即可。

### 着色模式

实体视图默认是**整件同色 + 光照明暗**，也就是零件本来的样子；
要"用颜色表达信息"时才切到逐面取色的模式：

| 模式 | 含义 |
|------|------|
| 整件同色（默认，`auto`） | 每个对象一种本色，明暗全部交给光照 |
| 单色平面（`uniform`） | 同上，但关闭逐顶点插值，直接看到三角面片 |
| 按分量（`component`） | 每个连通分量一种颜色，用来区分零件/毛坯 |
| 按曲率（`curvature`） | 曲率热力图，找尖边与过渡区 |
| 按法向（`orientation`） | 法向彩虹图（R/G/B = 0.5+0.5·n），看表面朝向 |

> 早期版本把默认的 `auto` 接到了法向彩虹图上，实体视图看起来像一张花花的
> 贴图 —— 这正是之前反馈的"模型显示失真"的来源，现已拆分为独立的
> `orientation` 模式。开启"载入时焊接顶点"（默认开）后，`--smooth` 或
> 设置里的"插值法向"才能让曲面呈现平滑过渡。

### 鼠标 / 键盘操作

**所有视图操作都以画布中心为原点**：`Camera.pivot`（即 `target`）恒投影在
画布正中心。左键拖拽绕该支点旋转；中键 / 右键 / Shift+左键平移严格跟随光标，
平移后支点仍落在画布中心；滚轮、Alt+左键与 `+/-` 都以该支点为锚点缩放，
缩放与光标位置无关。GUI 统一调用 `orbit_about_center` / `pan_about_center` /
`dolly_about_center`，不会再出现「绕世界原点转 / 一缩放模型就跑掉」。

**不会一下就过头**：默认旋转 `0.12°/像素`、滚轮每档 `7%`，并对单个鼠标事件
的位移限幅（旋转/缩放 60 px、平移 120 px）。小幅移动增益更低（`0.55~1.0`
随位移平滑过渡），既能对准细节又不会一次甩出去；拖拽中按住 **Shift** 进入
精细模式（旋转/缩放降到 1/4）。Alt+左键缩放从每像素 `0.12` 档降到
`0.02` 档，拖 100 px 仅约 15%，不再一拖就冲到极限。

| 操作 | 功能 |
|------|------|
| 左键拖拽 | 轨道旋转 |
| Ctrl + 左键拖拽 / 开启 Rotate around Z | 绕 Z 轴（回转轴）旋转 |
| 中键拖拽 | 平移 |
| 右键拖拽 | 平移 |
| 右键单击 | 弹出上下文菜单 |
| Shift + 左键拖拽 | 平移 |
| 拖拽中按住 Shift | 精细模式：旋转/缩放降为 1/4 |
| Alt + 左键拖拽 | 缩放 |
| 滚轮 / 触控板 | 缩放（支持 `pixelDelta`） |
| 左键单击 | 测量模式下取点（**把模型投影到屏幕后取真实表面点**；空白处退回视图平面，画布任意位置都能点；手抖 ≤12px 仍算点击） |
| 双击 | 适配窗口（测量进行中不触发，避免连点取点时视角跳变） |
| 方向键 | 旋转；Shift+方向键 平移；Ctrl+方向键 绕 Z / 俯仰 |
| `+` / `-` | 缩放 |
| `F` / `Home` | 适配窗口 |

同步显示当前操作与帧率。

### Zoom Fit：按当前视角精确适配

旧实现用包围盒**外接球半径** `‖hi-lo‖/2` 估算相机距离：对细长件极不准确
（`HLFΦ0.20-6.5.stl` 是 `0.2 × 0.2 × 11`，外接球半径 5.5），切到俯视只剩
十几像素，这就是「zoom fit 没匹配视图大小，显示很小」。

现在把可见对象的真实顶点（超过 20 万等间隔抽样）变换到当前相机基下，
逐点解透视投影不等式并取最大距离：

```
ndc_y = y / (tan_half · (d − z))      ⇒ d ≥ z + margin·|y| / tan_half
ndc_x = x / (aspect · tan_half · (d − z))
                                      ⇒ d ≥ z + margin·|x| / (aspect·tan_half)
```

`margin=1.10`，因此任意视角、任意画布宽高比下模型都占满约 **90%** 视口。
`fit_view()` 会先把相机视口同步为真实画布像素尺寸（窗口最大化后约
`1648×940`，而不是构造时的 `1024×768`），并在布局稳定后再适配一次。
切换标准视图默认自动重新 fit；实测该针状件等轴测占竖直 81%、前视 91%、
俯视 82%（旧版俯视只有约 2%）。

### 渲染方式：OpenGL 硬件视口为主

**为什么必须换渲染方法**：纯 numpy 软件光栅化在 84.6 万面模型上单帧要
`1.1~1.3 s`。后台异步线程只能让 UI「不阻塞」，画面仍是一秒一帧，看起来
就是「一操作就卡」；降分辨率对这种规模几乎无效，因为瓶颈在三角形数量。

现在界面优先用 `QOpenGLWidget`（PyQt5 自带，无需 PyOpenGL）：

* 顶点位置 / 法线 / 基础色交错成 VBO，**一次性上传**（该模型约 91 MB，
  首帧约 130~320 ms），之后每帧只更新 MVP / 光照 uniform；
* GLSL 里做与软件渲染器一致的双光源 Blinn-Phong 着色，硬件深度缓冲负责
  遮挡（天然没有分批排序问题），4× MSAA 抗锯齿；
* 线框 / 棱边用 `glPolygonMode(GL_LINE)` 复用同一 VBO；
* 坐标轴、网格、测量标注、中心支点标记、提示文字由透明子控件用
  `QPainter` 投影绘制（QPainter 不能直接画到 GL 的 FBO 上）。

实测（`1648×940` 画布，84.6 万面）：GL 内部约 **1 ms/帧**，事件循环连续
旋转 **≈54 fps**，鼠标事件处理 `< 1 ms`。软件渲染器继续用于**保存图片、
命令行导出**，以及没有 GL 上下文时的自动回退（`Extras/设置` 中
`UseOpenGL=False` 也可强制回退）。

### 测量：把模型投影到屏幕再取点（纯 CPU，点击必定生效）

测量取点的做法是**把当前视图下的模型投影到屏幕**，再按屏幕位置回到模型表面：

1. 打开测量工具时，把当前视图下所有可见模型的顶点投影到屏幕，按 16 像素一格
   把每个三角形的屏幕包围盒登记进二维格子索引（`stl_viewer/screenpick.py`）；
2. 点击时只取该像素所在格子里的那几个三角形，做**精确的射线-三角形求交**，
   取最近命中点 —— 得到的是**真实表面点**，两点距离就是真实三维尺寸，
   与视角、缩放都无关；
3. 视图或模型变了，索引在需要时自动重建；测量中视图静止 250 ms 后也会提前
   建好，所以转完视角停一下再点，第一次点击同样是即时的。

为什么不用 GL 深度拾取（离屏 FBO 画两遍 + `glReadPixels`）：读回像素对驱动和
上下文状态很敏感，实际机器上一按就卡住 —— 用户报障的「第一个点就点不了」就是
它导致的。现在**整条取点路径不调用任何 GL 接口**，改成纯 numpy 计算，
84.6 万面的针规模型上单击 17–27 ms，点击不会丢。

| 点到什么 | 取到的点 |
|---|---|
| 模型上 | 真实表面点（格子索引 + 精确求交），量出真实三维尺寸 |
| 轮廓最外一圈像素（几何边缘差半个像素） | 吸附到最近的可见边缘，仍是真实表面，不退回视图平面 |
| 空白处（模型外 / 背景 / 空场景） | 投影到视图平面（过第一个已取点或支点），任意位置都能取点 |

配套细节：

* 状态栏标明本次取点来源：「取模型表面点（真实三维尺寸）」/「取视图平面点（空白处）」；
* 线段结果额外给出 **ΔX/ΔY/ΔZ**：斜视角下点了圆柱端面的轮廓极值时，能立刻
  看出「Z 向确实是 40.000，多出来的是端面半径」；
* 鼠标停住 90 ms 后用真实深度刷新预览（复用已有索引，不重建），
  **按下之前看到的长度就是最终结果**；移动过程中只做零开销的平面预览；
* 屏幕跨度不足 15 像素时提示「放大后再测更准」：0.2 mm 在 828 px 画布上只有
  11 px，点击精度本身就是 ±1 px；
* 测量模式下移动鼠标实时显示「橡皮筋 + 当前段长」；按 `Esc` 取消进行中的测量。

精度上限（明确写出来，避免误判成 bug）：圆柱轮廓是**相切**的，切线附近整段
圆弧被压进 1–2 个像素，点最外侧那一列像素必然落在 13° 左右的圆周上，
所以「点两条轮廓线量直径」会有约 1.5%–2.5% 的系统偏小 —— 这是光栅化极限。
量平面上的特征（台阶宽度、孔心距、端面长度）则是像素级精度。

### 两点测圆：先点圆心，圆随光标实时确定

两点测圆按标准语义实现，不是「两点当直径」：

1. **第一次点击 = 圆心**：点下立即落定圆心，并画出以该点为中心的圆；
2. 之后移动光标，**圆随光标到圆心的距离实时缩放**，同时显示虚线半径与
   `⌀直径 R半径` 读数；
3. **第二次点击 = 圆周上一点**，半径由此确定，测量入库。半径取第二点在
   「过圆心、垂直视线」平面内的投影距离，因此画出来的圆严格经过光标点
   （斜视角下两点深度不同时也不会「圆跟不上光标」）。

配套的健壮性处理（都是「点了没反应」类问题的根因）：

* **完成一次后同工具保持激活**（连续测量），不必回菜单重新点工具；
* 两点重合 / 三点共线时**拒绝入库并保留已有点**，状态栏提示换个位置，
  不会再出现「测量凭空消失、画面什么都没有」；
* 按下鼠标后手抖移动 ≤12 px 仍算一次取点（只有明显拖动才转为旋转），
  高 DPI 屏 / 触控板下不会漏点；
* 测量中快速连点被 Qt 合成为「双击」时**不触发 zoom fit**，视角不会突然跳变。


### 交互拾取：GPU 深度拾取（选点/吸附瞬时、不卡）

选点不再依赖软件渲染器的 CPU 全量射线-三角形相交（84.6 万面单次要
`~1.1 s`，拖动选点会明显卡顿）。改为在缩小的离屏 FBO（≤1024 px）里分两遍渲染：

* 第一遍把「对象编号」写入 RGB，第二遍把「表面窗口深度」编码进 RGB（24 位精度）；
  两遍都只依赖 `GL_RGBA/GL_FLOAT` 的颜色读回，**绝不读 `GL_DEPTH_COMPONENT`**
  —— 当 FBO 深度附件是 `GL_DEPTH24_STENCIL8`（Qt 常见默认）时该组合非法、
  驱动会返回清屏值 `1.0`，导致「点在模型上却永远拾取不到」。
* 读回的 1 像素经 MVP 逆矩阵反投影回世界坐标，得到模型表面真实点；深度 24 位
  编码保证重建误差仅亚像素量级（符合 GPU 像素拾取精度）。
* 大面数模型整件同色时自动去掉逐顶点颜色、改用 uniform 上色，VBO 显存省约 1/3；
  单对象 VBO 体积 > 15 GB 时放弃上传并回退软件路径，避免 OOM。
* 实测 84.6 万面模型：拾取一次 < 10 ms（含两遍渲染 + 读回 + 反投影）。

> 注：PyQt5 的 `QOpenGLFunctions.glReadPixels` 在本机只接受 `GL_RGBA/GL_FLOAT`
> 并返回浮点元组，旧式指针形式会抛 `TypeError`、`UNSIGNED_BYTE` 会抛
> `ValueError`；此处已统一用浮点元组读回再把 8-bit 值还原为整数。

### 高分屏 / Windows 缩放适配

`QOpenGLWidget` 的内部帧缓冲尺寸是「逻辑尺寸 × 设备像素比（DPR）」。若
`glViewport` 仍用逻辑尺寸，模型会被画到帧缓冲左下角（典型表现：高分屏 /
缩放屏下模型只占画布一角、各种变换越不出该区域）。现在 `resizeGL` 与
`paintGL` 都通过 `_fb_size()` 乘上 `devicePixelRatioF()`，缩放屏下模型也能
遍及整个画布、变换不再受限。

### 软件回退路径的画质与调度

**后台异步渲染**：软件光栅化放进单线程工作池，GUI 线程只合成已完成的
位图；任务携带状态快照，忙时只记「有待渲染」不堆积，提交一帧约 `0 ms`。

**渐进式渲染 + 像素预算**：视图变化先出快帧，空闲 `90 ms` 后精修；
交互帧按窗口面积封顶 80 万像素、精修帧按 `w·h·ss²` 封顶 220 万像素。
静止帧始终 1:1 全分辨率、不做平滑放大；降分辨率位图由高度反推宽度
（`w = round(W·h/H)`），宽高比严格一致，不会拉扁/拉长。

**自适应分辨率**：拖拽 / 动画期间上限默认 85%，按实测帧耗时往 30fps
收敛（下限 35%，带 1.5×/0.5× 迟滞，避免忽清忽糊）。

**打开大模型不做深度统计**：`Mesh.statistics(deep=True)` 在 84 万面模型上
要十几秒（连通分量 / 边使用计数）。打开文件时只用面数显示提示；
`Statistics` 对话框对 > 20 万面的模型自动跳过深度统计，避免点一下就冻住。

**鼠标灵敏度可调**：`View > 视图选项` 三个滑条，旋转 / 平移 / 缩放默认
`0.12 °/px` / `1.0` / `0.07`。

### 显示失真的四处根因修复

1. **反向绕序三角形深度取反**：边函数已乘绕向符号，重心坐标的分母却仍用
   带符号 `area`，约一半三角形（背面）的 NDC 深度变成相反数，远面因此
   通过深度测试盖住近面 —— 实体看起来半透明、内部螺旋槽透出来。分母改为
   `1/|area|`，`samples/preview_solid.png` 可直接看到修复后的实心表面。
2. **同批内遮挡顺序**：不透明路径按 bbox 尺寸分桶后批内不再按深度排序，
   而 numpy 对重复像素下标只保留最后一次写入，全局 Z 缓冲管不了同一批的
   覆盖。现在每个分桶内部统一按「远 → 近」排列。
3. **投影口径不一致**：透视投影矩阵没纳入 `zoom`（`visible_height` /
   `world_per_pixel` 却除了），`Camera.up()` 也未与视线正交，导致缩放无效、
   平移不跟手、拾取偏移。现在投影 / 屏幕射线 / 平移共用同一口径：
   `project → ray_to_plane` 往返误差 `< 1e-14`，平移 45 px 恰好位移 45 px。
4. **背面 Z-fighting**：默认不剔除背面时，封闭实体的背面三角形会在共享
   深度处与正面抢像素，放大看是一条条细缝与斑点。现在默认剔除背面，
   表面更干净、实测还快约 35%；需要观察开放曲面背面时用
   `Mesh > Back and Front` 打开。

## 6. 关键实现说明

- **软件光栅化**：三角形填充使用规范化重心坐标，`edge` 与深度均以
  `c + d·j` **线性增量**方式计算，深度只在真正命中的像素上求值
  （不再构造整幅 `(B,mh,mw)` 中间数组）。
- **按尺寸分桶分批**：一批三角形共用一块 `(B, mh, mw)` 矩形。若直接取批内
  `max(bw)/max(bh)`，一个 31×170 的三角形会把同批全部撑成 31×170，
  实测空洞率达 **8.0×**；改为按 bbox 边长的 2 次幂分桶后降到 **2.0×**，
  光栅化耗时随之下降一半以上。不透明路径遮挡由 Z 缓冲保证，分桶不影响正确性；
  透明混合路径仍保持全局"远 → 近"分批。
- **命中像素解算**：用 `flatnonzero` + `divmod` 由线性下标反解 `(批, 行, 列)`，
  再用 `row_base[tri] + ry*W + rx` 求像素下标 —— 只在 B 个元素里随机取值，
  比按 `(B*mh)` 规模去 `ys.ravel()` 里取快约 3 倍。
- **缓冲复用**：`color/depth/alpha` 三块全尺寸数组按渲染尺寸缓存复用，
  超采样时不再每帧 malloc/free 数十 MB；降采样直接对 uint8 视图分两步求和，
  省掉一份全尺寸 float32 副本。
- **坐标约定**：`Z` 为旋转 / 回转轴（朝上）。
- **载入自动焊接**：STL 常把同一个几何点按三角形重复存储（三角汤），
  不焊接时每个三角形都是独立连通分量 —— 体积算不出、边界边满天飞
  （示例件 4212 顶点 / 4212 条边界边 → 焊接后 1027 顶点 / 640 条）。
  容差取包围盒对角线的 `1e-6`，可用 `--no-weld` 或视图选项关闭。
- **PNG**：`png.py` 自行实现 zlib + 逐行滤波，支持 8 位非隔行、全部滤波器，
  读写均不依赖第三方库。
- **字体**：`font5x7.py` 内置 5×7 位图字形，用于画布上的标注与 HUD 文字。
- **测量**：支持 `point3d`、`line3d`、`line2d`、`circle2p`、`circle3p`、
  `angle2d`、`rzpoint` 七种类型；`rzpoint` 输出柱坐标 (R, Z, θ)。
- **内嵌模型提取**：`stl_io.extract_embedded_mesh` 可从 `.exe` / `.stpack`
  中扫描并解出内嵌的 STL / zlib 流，以兼容"自包含导出件"。

### 实测性能（Windows / CPython 3.13 / Qt 5.15 / OpenGL 4.6）

| 场景 | 模型 | 帧耗时 | 交互表现 |
|------|------|--------|----------|
| GL 视口，1648×940 | `HLFΦ0.20-6.5.stl`，845,976 面 | GL 内部 ≈1 ms | 事件循环连续旋转 **≈54 fps** |
| GL 视口，1648×940 | 同上，首次上传 VBO | 130~320 ms（一次性） | 之后每帧只更新矩阵 |
| GL 视口，1648×940 | 示例件 1,404 面 | ≈1.6 ms | 硬件 MSAA，静止/拖拽同样清晰 |
| 软件回退，1170×824 | 845,976 面 | ≈1.1~1.3 s | UI 不阻塞，但画面更新慢 → 应优先用 GL |

> 软件后端对超大模型只能保证「不卡死」，做不到「不卡」；这正是必须引入
> 硬件视口的原因。没有 GL 上下文时程序仍可用，只是这类模型交互会明显变慢。

10. **测试套件梳理**：改用 pytest 跑 `test_core.py`、其余回归脚本各自携带
    `check()` 框架直接运行，合计 **183 项** 检查（详见第 7 节）。

> 测量精度上限（避免误判成 bug）：圆柱轮廓相切处整段圆弧被压进 1–2 像素，

> 前视直径、平面两点距离、iso 轴向分量均在容差内。
